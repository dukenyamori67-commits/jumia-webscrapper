## 📌 Project Overview

This project builds an end-to-end data pipeline that extracts product data from Jumia using web scraping, transforms the data, and loads it into a PostgreSQL database for analysis.

---

## ⚙️ Tech Stack

- Python
- BeautifulSoup
- Requests
- PostgreSQL
- SQL
- Pandas

---

## 🧠 Skills Demonstrated

- Web scraping automation
- Data cleaning and transformation
- Database schema design
- ETL pipeline development
- SQL querying
- Version control using Git & GitHub

## 🔄 Data Pipeline Architecture

```
        Jumia Website

     BeautifulSoup Scraper
```

## 🚀 How to Run the Project

```bash
git clone https://github.com/dukenyamori67-commits/jumia-webscrapper.git
cd jumia-webscrapper
pip install -r requirements.txt
python src/jumia_scraper.py
```
